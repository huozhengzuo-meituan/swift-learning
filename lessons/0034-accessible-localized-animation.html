动画描述状态变化，尊重减少动态效果

SwiftUI 在状态变化前后插值，withAnimation 表达一次操作的过渡，animation(_:value:) 针对指定值触发。不要用一个覆盖整个根视图的隐式动画让所有输入和加载状态都跟着移动。示例切换完成状态时读取 accessibilityReduceMotion，若开启便不使用该动画；完成信息还通过文字和图标表达，不能只靠绿色。减少动态效果不仅是速度更快，而是避免不必要的大幅位移。

@Environment(\.accessibilityReduceMotion) private var reduceMotion
// 明确限制到这次状态切换。
try withAnimation(reduceMotion ? nil : .easeInOut(duration: 0.2)) {
    try StudyWriter.toggle(item, in: context)
}

给控件语义，并承受字号变化

系统 Button、Toggle、TextField 已有基础语义，优先复用它们。图标需要可理解的 label；纯装饰图标可以隐藏，真正表达完成状态的图标则提供状态文字。StudyRow 将图标、标题、时间合并为一个可读元素，减少无意义的重复停靠，但不要把多个独立按钮错误合并成一个不可操作区域。语义字体和多行布局允许较大字号；VoiceOver 阅读顺序、操作命名和键盘焦点必须实际体验。

Image(systemName: item.isCompleted ? "checkmark.circle.fill" : "circle")
    .accessibilityLabel(item.isCompleted ? Text("Completed") : Text("In progress"))
// 行容器只组合展示信息，按钮仍应保留自己的动作。
.accessibilityElement(children: .combine)

界面文案翻译，用户内容保留原样

示例 Localizable.xcstrings 保存英文和简体中文文案。Text 的字符串字面量通常走本地化查找，用户输入的 item.title 是动态 String，应原样呈现。错误消息在非 View 代码中用 String(localized:)；日期用 format API 随 locale 适配。不要用拼接句子和手写月日顺序替代格式化，也不要将用户标题误当本地化 key。新增文案时同步目录并测试较长翻译，语言切换可能暴露布局问题。

Text("Study details") // UI 字面量：目录中的翻译键。
Text(item.title)       // 用户内容：直接展示。
Text(item.createdAt, format: .dateTime.month().day())
let message = String(localized: "Unable to save")

NativeStudy · StudyDetailView.swift

open examples/NativeStudy/NativeStudy.xcodeproj；选择 NativeStudy-macOS → My Mac → ⌘R（iOS 选择 NativeStudy-iOS 和模拟器）。

终端命令默认在 swift-learning 根目录执行；说明为 Xcode 操作时，跟随项目 README。

动手：进行一次包含无障碍和本地化的功能验收。

  1. 在 Xcode Scheme → Run → Options 设置 App Language 为简体中文，再切换英文。
  2. 使用 macOS VoiceOver（⌘F5）或模拟器 Accessibility Inspector 检查列表行和操作名称。
  3. 开启系统 Reduce Motion，增大文字尺寸，并在窄屏完成新增、编辑、保存。
验收现象

中文英文文案可用；用户原始内容不被翻译；完成状态不依赖颜色；大字号下仍能访问保存与取消。

先独立完成，再展开参考解法

逐项记录实测平台和结果。可以在 Preview 使用 locale 与 dynamicTypeSize 做视觉检查，但 Preview 通过不代表真实 VoiceOver 或键盘导航已验收。

StudyListView()
    .environment(StudyPreferences())
    .modelContainer(container)
    .environment(\.locale, Locale(identifier: "zh-Hans"))
    .environment(\.dynamicTypeSize, .accessibility3)

从前端迁移时，留意这些误区

  • 不要把颜色当成唯一信息通道。
  • 不要把 Preview 注入环境等同于真实辅助技术验证。

即时自测

只用绿色表示完成状态，足以覆盖所有用户的感知需要。

本课的一个成果实现主题频次统计，并解释 Array、Set、Dictionary 的不同承诺。

先问数据需要什么，再选容器

Array 保留顺序并允许重复；Set 保留唯一值但不保证展示顺序；Dictionary 关联键和值，也不承诺可用于 UI 的排序。Set 元素和 Dictionary 键需要 Hashable。Swift 容器通常有统一元素类型，例如 [String]、Set<String>、[String: Int]，无需把所有东西塞进 Any 后再猜类型。

let topics = ["Swift", "UI", "Swift"]
let distinct = Set(topics)        // 唯一主题有 2 个
var counts: [String: Int] = [:]  // 空字典仍有确定类型
for topic in topics {
    counts[topic, default: 0] += 1
}

循环表达遍历，分支表达业务条件

for item in items 直接遍历元素，避免手写下标越界。如果确实需要索引，优先用 indices 或 enumerated。0..<n 不包含 n；1...n 包含 n，但 n 为 0 时不适合当作空循环。if 的条件需要 Bool；switch 每个分支默认不穿透到下一个，不需要 JavaScript 风格的每段 break。

for (index, topic) in topics.enumerated() {
    if topic == "Swift" { print("\(index): \(topic)") }
}
// 空数组的 indices 是空集合，循环自然执行零次。
for index in topics.indices { print(topics[index]) }

计算无序，展示有序

统计函数只返回字典，将展示顺序留给调用者决定。CLI 使用 sorted 按主题名排序后输出，确保重复运行结果稳定。这个分离在原生列表里很有用：模型不应偷偷依赖某次字典的内存布局，界面也不应因重启随机换顺序。数组的下标必须有效；访问不存在的位置会陷阱，不能期待得到 undefined。

for (topic, count) in topicCounts(topics).sorted(by: { $0.key < $1.key }) {
    print("\(topic)：\(count)")
}
// Swift：2
// UI：1

验收现象

原输入得到 ["Swift": 2, "UI": 1]；空输入返回空字典；展示顺序通过排序显式指定。

先独立完成，再展开参考解法
public func topicCounts(_ topics: [String]) -> [String: Int] {
    var counts: [String: Int] = [:]
    for topic in topics {
        counts[topic, default: 0] += 1
    }
    return counts
}

带 default 的字典下标允许对不存在的键从零开始累计。普通读取 counts[topic] 返回 Optional，下一课会解释原因。

从前端迁移时，留意这些误区

  • 数组越界不是返回 nil，而是运行时错误。
  • Dictionary 和 Set 的迭代顺序不能作为产品展示规则。

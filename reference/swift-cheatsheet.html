Swift 语法速查

先让编译器帮你表达约束，再追求简短写法。

绑定、类型与 Optional

let name: String = "Swift"
var minutes = 25
let ratio = Double(2) / Double(5) // 0.4，避免整数除法
let raw: String? = "25"
func parse(_ text: String?) -> Int? {
    guard let text, let value = Int(text), value > 0 else { return nil }
    return value
}
let fallback = parse(raw) ?? 10 // nil 才使用默认值

函数、闭包与集合

func label(for title: String, minutes: Int = 25) -> String {
    "\(title)：\(minutes) 分钟" // 单表达式函数可省略 return
}
let values = [1, 2, 3, 4]
let result = values.filter { $0.isMultiple(of: 2) }.map { $0 * 10 }
// 结果 [20, 40]；数组越界不会返回 undefined，而是运行时错误。

用类型表达数据状态

struct Session: Equatable, Sendable {
    let title: String
    var completed = false
    mutating func finish() { completed = true }
}
enum LoadState<Value> {
    case idle
    case loading
    case loaded(Value)
    case failed(String)
}
protocol Named { var title: String { get } }
func describe<T: Named>(_ value: T) -> String { value.title }
选择适用情境注意
struct独立值、业务模型、传输数据值内的 class 属性仍可能共享。
class身份、共享生命周期、继承或观察模型ARC 引用环需分析；默认可变共享不跨并发边界。
enum + 关联值互斥状态、路由、明确错误用 switch 穷尽处理，别让无效组合成为可能。
some P隐藏但固定的具体返回类型不同返回分支不能任意换具体类型。
any P运行时装入不同符合协议的类型存在类型的操作能力受协议约束限制。

错误和清理

enum ValidationError: Error { case emptyTitle }
func validate(_ title: String) throws -> String {
    guard !title.isEmpty else { throw ValidationError.emptyTitle }
    return title
}

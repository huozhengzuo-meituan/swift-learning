用已有经验搭桥，保留语言和平台之间真正的差异。

课程统一术语

术语本课程含义易混淆点
值语义 value semantics赋值后，从可观察行为看拥有独立值；修改副本不应改变原值。struct 内若存 class 引用，仍会共享引用对象。
引用语义 reference semantics多个变量可指向同一实例；用 === 判断身份。let 固定引用绑定，不冻结对象所有属性。
Optional 可选值显式表达有值/无值的枚举：T?。不是任意值都能塞 nil，也没有隐式 truthy/falsy。
协议 protocol类型声明遵循的一组能力约定，可配扩展。不是仅供擦除的 TypeScript 类型别名。
泛型 generic在约束下保留具体类型信息。any P 容器与 some P 不透明类型不是同义词。
闭包 closure可捕获周围值的函数值。逃逸闭包可能延长对象生命周期；捕获需分析。
隔离 isolation限定谁可以访问某份可变状态的边界。不是“永远在某个 OS 线程”。
挂起 suspensionasync 工作暂时让出执行机会，之后可继续。await 不必每次真的挂起，也不等于阻塞线程。
结构化并发 structured concurrency子任务的生命周期受词法作用域约束。Task {} 与 Task.detached {} 创建的不是结构化子任务。
actor保护其隔离状态的引用类型。跨 await 可能重入，不保证整个 async 方法原子。
MainActorUI 常用的全局 actor 隔离域。Observation 不自动提供它；大量同步工作仍可能阻塞 UI。
Sendable类型可跨并发域安全共享/传递的契约。不是为消除错误随意添加的标签；不等于任意内部变更都安全。
真值来源 source of truth一份数据的权威拥有者，其他界面通过输入或绑定访问。不要为父子视图各复制一个独立可变状态。
身份 identitySwiftUI 关联状态和生命周期的依据。稳定 ID 与显示位置不同；每次 body 新建 UUID 会重置身份。
DTO用于边界传输的简单数据值。持久实体和跨 actor 的传输值不必是同一类型。
Deployment Target应用允许运行的最低 OS 版本。不同于当前 SDK、Swift 编译器和语言模式。
Preview开发时的预览运行环境。预览可用不等于真机、磁盘持久化或发布可用。

从 Web 出发的对照表

熟悉的概念可以借助的直觉必须重新学习
const / let尽量限制不必要的可变性。Swift let/var 与 class 引用可变性的分层。
null / undefined缺少值应显式处理。Optional 绑定、guard、类型安全；避免随手强制解包。
Promise / async异步操作可能成功、失败。结构化任务、取消传播、actor 隔离；不是事件循环模型复制品。
组件 state状态决定界面。SwiftUI View 是短生命周期描述值，状态与身份关联。
props / callbacks子组件接收数据与动作。Binding 是读写投影，@Bindable 不拥有模型。
Context依赖可从祖先传入。Environment 与 scene/window 范围；缺依赖会影响 Preview。
CSS 布局拆解尺寸与对齐。布局提议/测量/放置、修饰符顺序、平台默认样式。
npm package模块和依赖图。SwiftPM target、product、访问控制、语言模式。
DevTools先观察再判断。Xcode、Instruments、ARC 持有链、原生控件状态。
